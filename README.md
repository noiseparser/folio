# Folio

Folio is a focused workspace for managing client accounts, relationships, deals, and follow-ups. It gives small teams a shared view of portfolio health without the overhead of an enterprise CRM.

## What it includes

- Account and contact workspace
- Deal pipeline with clear stages
- Portfolio health overview
- Relationship activity feed
- Follow-up task management
- Fast account search and filtering

## Development

Folio requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Run the production build and rendered-page check with:

```bash
npm test
```
